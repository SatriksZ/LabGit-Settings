# LabGit-Settings
## Название проекта
LabGit-Settings — учебный проект по настройке репозитория GitHub.
## Назначение проекта
Демонстрация работы с системой контроля версий: структура каталогов, фильтры исключения, обработка типов файлов.
## Структура каталогов
- `src/` — исходный код (Program.cs)
- `docs/` — документация проекта
- `tests/` — тестовые материалы
- `assets/` — вспомогательные материалы
- `.gitignore` — правила исключения файлов
- `.gitattributes` — правила обработки типов файлов
- `README.md` — описание проекта
## Исключаемые типы файлов
- Каталоги сборки: `build/`, `bin/`, `obj/`
- Временные файлы: `temp/`, `*.tmp`, `*.temp`
- Журналы: `logs/`, `*.log`
- Локальные настройки: `.env`, `appsettings.Local.json`
- Файлы ОС: `Thumbs.db`, `.DS_Store`
- Файлы IDE: `.vs/`, `.vscode/`, `*.user`, `*.suo`
- Результаты тестирования: `TestResults/`
## Настройки репозитория
- Настроен `.gitignore` для исключения служебных файлов.
- Настроен `.gitattributes` для корректной обработки текстовых и бинарных файлов.
- Организована структура каталогов по назначению файлов.
